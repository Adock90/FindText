# FindText
A simple python script to find phrases in files and files in directories

<h1>To Run:</h1>
  1. git clone it or download the zip file
  <code>git clone https://github.com/Adock90/FindText</code>
  
  2. Run with python or python3
  <code>python3 findText.py "hi" hi.txt --file</code>
  <code>python3 findText.py "#include <gtk/gtk.h>" /usr/include/ --dir</code>
